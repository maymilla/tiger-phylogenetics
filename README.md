# tiger-phylogenetics
Tugas Besar IF3211 Komputasi Domain Spesifik

Cara Menjalankan Program:
1. Clone Repo
2. Download mafft-7.526-win64-signed
3. Ekstrak dan sesuaikan MAFFT_PATH di file run_mafft.py sesuai dengan path dari mafft yang sudah di-download
4. Jalankan file main.py
```bash
python main.py
```
